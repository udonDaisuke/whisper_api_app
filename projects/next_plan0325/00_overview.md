# MemoRec プロジェクト概要

> 最終更新: 2026-03-25
> ステータス: 開発初期段階 (v0.1.0)

## コンセプト

**MemoRec** はリアルタイム音声文字起こしWebアプリケーションである。

ブラウザのマイクから音声をキャプチャし、WebSocket経由でサーバーへストリーミング送信、OpenAI Whisperモデルでリアルタイムに文字起こしを行う。現時点では日本語の音声認識を主対象とする。

## インフラ戦略

段階的にスケールさせる方針を採用する。

```
Stage 1: 自宅端末 (16GB RAM) + Faster Whisper (CPU)
  → 開発環境で動くレベル、最小コスト、効果見極め
    |
Stage 2: 効果確認後、外部 VPS へ移行 (CPU)
  → 外部公開・安定運用
    |
Stage 3: VPS で GPU インスタンスへ移行 + モデル大型化
  → 高精度・高機能化
```

詳細は [05_infrastructure_cost.md](./05_infrastructure_cost.md) を参照。

## 将来ビジョン

オーナーフィードバック (Issue #1) に基づく将来構想:

- **トピック検出**: 録音中の会話から「今何の話をしているか」をリアルタイムで取得する
- **タグ付け**: 録音・文字起こし結果に対して後からタグを付与できるようにする
- **話者特定 (Speaker Diarization)**: 誰が話しているかを識別する (後処理)
- **感情認識**: イントネーションや声の雰囲気から話者の感情を読み取り、メタデータとして付与する (後処理)
- **音声変換・キャラクター再生**: 感情メタデータを含めた音声データを、任意のキャラクターの声で再生できるようにする (後処理)

**注**: 話者特定・感情認識・音声変換はリアルタイムではなく後処理として実装する。これによりCPU環境でも実現可能となり、GPU移行は処理速度がボトルネックになった段階で検討する。

## アーキテクチャ概要

```
[ブラウザ (Web Audio API + AudioWorklet)]
    | PCM16LE音声データ (WebSocket)
[FastAPI バックエンド]
    |
[OpenAI Whisper (ローカル実行)]
    | テキスト結果
[ブラウザへ返送 (WebSocket)]
```

詳細は [01_architecture.md](./01_architecture.md) を参照。
