## Phase 4: 高度な音声分析機能

オーナーの将来ビジョンに基づく高度な分析機能群。

### 4-1: トピック検出

- 録音中の会話から「今何の話をしているか」をリアルタイムで取得
- LLM (大規模言語モデル) による文字起こしテキストのトピック分類
- トピック遷移のタイムライン表示

### 4-2: 話者特定 (Speaker Diarization)

- 誰が話しているかを自動識別
- 話者ごとに文字起こしテキストを分離表示
- 話者プロファイルの登録・学習

### 4-3: 感情認識

- イントネーション・声のトーンから話者の感情を推定
- 感情メタデータ (喜怒哀楽・興奮度など) の付与
- 感情の時系列変化の可視化

### 技術的検討事項

| 機能 | 候補技術 | 備考 |
|---|---|---|
| トピック検出 | OpenAI API / ローカルLLM | リアルタイム性とコストのトレードオフ |
| 話者特定 | pyannote.audio / resemblyzer | Whisperとの統合方式を検討 |
| 感情認識 | SpeechBrain / Wav2Vec2 | 音声特徴量からの推定モデル |

## Phase 5: 音声変換・キャラクター再生

感情メタデータを含めた音声変換と任意キャラクターでの再生機能。

### 構想

- 文字起こしテキスト + 感情メタデータを入力として音声合成
- 任意のキャラクターの声質で再生
- 感情を反映した自然なイントネーション生成

### 技術的検討事項

| 機能 | 候補技術 | 備考 |
|---|---|---|
| 音声合成 (TTS) | VOICEVOX / Style-Bert-VITS2 / XTTS | 日本語対応・感情制御が可能なもの |
| 声質変換 | RVC / so-vits-svc | リアルタイム性の要否で選定 |
| 感情制御 | スタイルベクトル / プロンプト制御 | TTSモデルの対応状況に依存 |
