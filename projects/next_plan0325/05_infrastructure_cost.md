## 前提条件

| 項目 | 値 |
|---|---|
| アプリケーション | MemoRec (リアルタイム音声文字起こし) |
| 推論モデル | OpenAI Whisper (CPU版: tiny〜small) |
| 最低要件 (tiny) | 2 vCPU / 4GB RAM |
| 推奨要件 (small) | 4 vCPU / 8GB RAM |
| 将来要件 (Phase 4-5) | GPU推論 or 高性能CPU / 16GB+ RAM |

| 為替レート | 1 USD ≈ 150 JPY, 1 EUR ≈ 165 JPY |

## 5. 推奨構成

### 個人開発・Phase 1-3

**推奨: 自宅ミニPC (N305)**

- 初期費用: 約 50,000円
- 月額: 約 500円 (電気代のみ)
- 1年間の総コスト: 約 56,000円
- 2年間の総コスト: 約 62,000円

VPS (ConoHa 4GB 36ヶ月) の場合、一括前払い 66,960円 + 管理費なしだが、自宅ミニPCは2年目以降 年間6,000円のみで圧倒的にコスト優位。ただし、外部公開が不要で開発用途のみであれば自宅がベスト。外部公開が必要な場合はVPSが手軽。

### 少人数利用・外部公開

**推奨: ConoHa VPS 4GB (36ヶ月まとめトク) + 自宅開発環境**

- VPS月額: 1,860円
- 年間: 22,320円 (一括前払い)
- 安定した外部公開環境と固定IPを確保

### Phase 4-5 への移行時

**推奨: 自宅GPU PC + クラウドGPUのハイブリッド**

- 開発・テスト: 自宅GPU PC (RTX 3060/4060)
- 本番・ピーク: RunPod/Vast.ai オンデマンド
- 月額目安: 自宅3,000円 + クラウド7,000円 (必要時のみ) = 約 10,000円

## 6. 注意事項

- 価格は2026年3月時点の調査に基づく。キャンペーンや為替変動で変わる可能性あり
- 自宅サーバーの場合、ISP契約によってはサーバー運用が規約違反になる場合がある
- Whisper smallモデル以上はメモリ使用量が大きいため、4GBプランではtinyモデル推奨
- GPU VPSの常時稼働は高コスト。オンデマンド運用やサーバーレスGPU (RunPod Serverless) も検討の価値あり
- 海外VPS利用時はWebSocketのレイテンシに注意。リアルタイム性が重要なMemoRecでは国内リージョン推奨
