# インフラコスト見積もり: 段階的移行戦略

> 最終更新: 2026-03-25
> 関連: [00_overview.md](./00_overview.md) | [03_roadmap.md](./03_roadmap.md) | [04_tech_stack.md](./04_tech_stack.md)

## 戦略概要

```
Stage 1: 自宅端末 (16GB RAM) + Faster Whisper (CPU, small, int8)
  → 最小コストで開発・効果見極め
  → 月額: ~500円 (電気代のみ)
    |
Stage 2: 外部 VPS (CPU) へ移行
  → 効果確認後、外部公開・安定運用
  → 月額: 1,700〜2,200円
    |
Stage 3: GPU VPS + モデル大型化
  → 後処理バッチの高速化、large-v3 モデル
  → 月額: オンデマンドで 7,000〜10,000円
```

---

## Stage 1: 自宅端末運用 (現在の目標)

### 前提条件

| 項目 | 値 |
|---|---|
| ハードウェア | 既存端末 (16GB RAM) を流用 |
| 推論エンジン | Faster Whisper (CTranslate2, CPU, int8) |
| モデル | small (メモリ ~1GB, 推論 ~0.5秒/1秒音声) |
| 用途 | 開発環境、個人利用、効果見極め |

### コスト

| 項目 | 費用 | 備考 |
|---|---|---|
| 初期費用 | **0円** | 既存端末を使用 |
| 月額電気代 | **約 250〜500円** | 消費電力 10〜20W 想定、31円/kWh |
| インターネット回線 | 0円 | 既存回線利用 |

### Stage 1 の年間コスト: **約 3,000〜6,000円**

### 効果見極めポイント

以下を評価し、Stage 2 移行を判断する:

- [ ] Faster Whisper (small, int8) のリアルタイム文字起こし精度は実用レベルか
- [ ] 16GB RAMで Faster Whisper + FastAPI + その他プロセスが安定動作するか
- [ ] 1秒チャンクでの推論遅延は許容範囲内か (目標: 0.5秒以内)
- [ ] Phase 4 の後処理 (話者特定等) のCPU処理時間は許容範囲か

## Stage 3: GPU VPS + モデル大型化

### 移行タイミング

- Phase 5 の後処理 (音声合成等) でCPU処理時間がボトルネックになった段階
- medium/large-v3 モデルで精度向上が必要になった段階

### 運用方針: オンデマンド + CPU常時稼働のハイブリッド

```
[常時稼働] VPS (CPU) — リアルタイム文字起こし (Faster Whisper small)
                |
                | 後処理ジョブをキューイング
                v
[オンデマンド] GPU VPS — 後処理バッチ実行 (話者特定・感情認識・音声合成)
                |
                | 処理完了後シャットダウン
                v
            結果を CPU VPS に返送
```

リアルタイム文字起こしは引き続きCPUで実行し、重い後処理のみGPUを使う。

### GPU VPS 候補

| プロバイダ | GPU | VRAM | 時間単価 | 1日4h利用の月額 | 備考 |
|---|---|---|---|---|---|
| **RunPod** | **L4** | **24GB** | **$0.39/hr** | **約 7,000円** | 秒単位課金、推奨 |
| RunPod | T4 | 16GB | $0.30/hr | 約 5,400円 | コスト重視 |
| Vast.ai | L4/T4 | 16-24GB | $0.20〜0.40/hr | 約 3,600〜7,200円 | マーケット価格変動あり |
| GCP | g2-standard-4 (L4) | 24GB | $0.76/hr | 約 13,700円 | 東京リージョンあり、安定 |

### Stage 3 推奨構成

**CPU VPS (常時) + RunPod L4 (オンデマンド)**

- CPU VPS: ConoHa 4GB = 1,860円/月
- GPU: RunPod L4 × 4h/日 = 約 7,000円/月
- **合計: 約 8,860円/月**

## 注意事項

- 価格は2026年3月時点の調査に基づく。キャンペーンや為替変動で変わる可能性あり
- 自宅サーバーの場合、ISP契約によってはサーバー運用が規約違反になる場合がある
- Faster Whisper small (int8) の実際の推論速度は端末の CPU 性能に依存する。Phase 1 で実測すること
- GPU VPS の常時稼働は高コスト。後処理のバッチ実行 + シャットダウンのオンデマンド運用を推奨
- 海外VPS利用時は WebSocket のレイテンシに注意。リアルタイム性が重要な MemoRec では国内リージョン推奨
